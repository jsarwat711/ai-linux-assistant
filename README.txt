=====================================================
  AI Linux Command Assistant
=====================================================

WINDOWS USERS:
--------------
1. Install Docker (Rancher Desktop):
   https://rancherdesktop.io

2. Double-click: run.bat
   (First run takes ~10 min to download AI model)

3. Browser opens automatically
   URL:      http://localhost:6080
   Password: aiassist


UBUNTU USERS:
-------------
1. Open Terminal in this folder

2. Run:
   chmod +x run.sh
   ./run.sh
   (First run takes ~10 min to download AI model)

3. Browser opens automatically
   URL:      http://localhost:6080
   Password: aiassist


NOTES:
------
- First run downloads AI model (~4.7 GB) ONCE only
- After first run, starts in under 30 seconds
- Works completely offline after first setup
- Press Enter in terminal window to stop app
